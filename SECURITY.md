# Security Reporting

Fluzo has no released runtime yet. Security requirements in the specifications
are not claims that an implementation has passed security testing.

Report a potential vulnerability privately using
[GitHub private vulnerability reporting](https://github.com/fluzo-labs/fluzo-docs/security/advisories/new).
For implementation issues, use the
[Fluzo implementation reporting form](https://github.com/fluzo-labs/fluzo/security/advisories/new).
Do not publish exploit details, credentials or private data in public issues.

Include affected revisions, a minimal reproduction, expected/observed behavior
and impact using synthetic data. If the private reporting form is unavailable,
do not put sensitive details into a public report; use GitHub Support to report
the unavailable channel.
